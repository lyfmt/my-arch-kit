TOP BARTRIM

DMS 顶栏精简方案：上半部分是现状和要删的东西，下半部分是三种菜单入口的摆法。顶栏保持现有的 P5 配色和形状，P3 风格只用于菜单本身。所有栏位模型按 1:1 逻辑像素绘制（42px 预留带，岛 40px 高、从 y=4 开始，卫星胶囊 28px）。

AFTER 精简后 · 三种入口

左边只剩工作区，中间是 Dank Island，右边只剩电量。差别只在 P3 菜单从哪里打开。每个方案分别画在 2560 宽的外接屏（HDMI-A-1）和 1706 宽的笔记本上；2560 的条比窗口宽，可以横向滚动。

方案 1 · 菜单牌放在最左，工作区之前 推荐

鼠标甩到左上角就能点到（屏幕角落是最好点的位置），和右侧电量左右对称。代价是需要写一个新的 bar widget（QML 补丁）。

方案 2 · 菜单牌放在最右，电量之后 备选

位置和原来的控制中心按钮一样，肌肉记忆不用改。但右上角在 niri 里常是窗口关闭键的方向，容易误点；右侧也显得比左侧重。

方案 3 · 不加按钮：右键岛 / 拉绳 / Mod+BackSpace 推荐

栏上不增加任何东西，最干净。菜单从岛上打开：右键岛，或者拉岛右下角挂着的拉绳（P5 改造里已有拉绳的概念，这里画的是拉绳打开菜单的样子，具体 QML 是否已有需要实现时确认），键盘用 Mod+BackSpace（在 ~/.config/niri 里查过，这个键目前没被占用）。缺点是新用户看不出入口。

可选 · 托盘未读小红点

托盘挪进菜单 APPS 页以后，飞书 / QQ 的未读提示会看不到。可以在菜单牌上加一个红点（只在托盘项处于 NeedsAttention 状态时出现）。方案 3 没有按钮，红点画在拉绳上。红色只用于这种提醒，符合调色板规则。

DECISIONS 逐项决定

元素决定挪到哪里失去什么怎么应用
workspaceSwitcher保留原位（左侧）无leftWidgets 保留
focusedWindow删除无替代位置栏上的窗口标题；P5WindowDossier 入口（复制 TITLE / APP ID / PID、ADD RULE、TAKE DOWN 强杀）。部分可用 Mod+Shift+W、Mod+P、Mod+Q 代替从 leftWidgets 删掉，热重载
systemTray删除P3 菜单 APPS 页专门的托盘区它是唯一的 StatusNotifier host。clash-verge、fcitx5、QQ、飞书这类只在托盘里的程序必须在 APPS 页有新家，否则只能走 IPC。风险最高的一项先做好 APPS 页托盘区，再从 rightWidgets 删掉
clipboard删除Mod+Alt+V；启动器 cb 触发词拖放存入、右键快捷菜单、widget toggle clipboard IPC 和 look.sh clip从 rightWidgets 删掉，热重载
cpuUsage删除P5HomeDash 的仪表；Ctrl+Alt+Delete 打开上游进程窗口（非 P5 样式）P5ProcessBoard 唯一的入口；look.sh proc 失效从 rightWidgets 删掉，热重载
memUsage删除同 cpuUsage同 cpuUsage从 rightWidgets 删掉，热重载
battery保留原位（右侧）无。笔记本上它是唯一常驻的电量显示，BatteryPopout 和电源模式也在这里rightWidgets 保留
controlCenterButton删除P3 菜单 SYSTEM 页用鼠标开关 Wi-Fi / 蓝牙 / 音频 / 夜间 / 深色模式的入口。IPC control-center toggle 仍在（会路由到岛），但没有快捷键SYSTEM 页做好后从 rightWidgets 删掉
centerWidgets删除无无。岛模式下这组配置根本不生效，只是清理删掉 music / clock / weather 三项
Dank Island保留原位（中间）无。方案 3 里它同时是菜单入口不改
P3 菜单入口新增方案 1 最左 / 方案 2 最右 / 方案 3 岛上—方案 1、2 需要新 widget 的 QML 补丁；方案 3 需要岛的右键 / 拉绳处理和一条 niri 绑定

应用步骤

改 ~/.config/DankMaterialShell/settings.json 的 barConfigs[0]，DMS 通过 FileView 监听文件，保存后立即生效，不用重建：

"leftWidgets":   ["p3Menu", "workspaceSwitcher"],   // 方案 1；方案 2、3 为 ["workspaceSwitcher"]
"centerWidgets": [],
"rightWidgets":  ["battery"]                         // 方案 2 为 ["battery", "p3Menu"]

新按钮（p3Menu 只是暂定 id）需要走 dms-p5 的流程：overlay 加 QML → 生成 patch → build.sh → scripts/dev.sh go 重启 DMS。方案 3 另外在 niri 加 Mod+BackSpace 绑定。

顺序很重要：先让 P3 菜单的 APPS 页能显示托盘、SYSTEM 页能代替控制中心，再删 systemTray 和 controlCenterButton。否则托盘程序（clash-verge、fcitx5、QQ、飞书）会暂时没有任何鼠标入口。其余几项可以现在就删。
